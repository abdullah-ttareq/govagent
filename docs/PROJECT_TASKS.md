# مهام مشروع GovAgent

ملف المهام الموحّد للمشروع. يحتوي **٥٩ مهمة** موزّعة على أربعة مجالات.

## كيف يُستخدم هذا الملف

- **التقسيم بعناوين المجالات للتنظيم فقط، لا لتوزيع الأشخاص.** أي عضو يستطيع
  تنفيذ أي مهمة يسندها إليه قائد الفريق.
- **قائد الفريق وحده** يحدّث حقول: المسؤول، الـBranch، الحالة.
- **بقية الأعضاء لا يعدّلون هذا الملف.** نفّذ المهمة المسندة إليك، وأبلغ قائد
  الفريق بالنتيجة ليحدّث الحالة.
- كل مهمة تحمل Prompt جاهزًا للنسخ إلى Claude. انسخه كما هو.

## الحالات المعتمدة

```
Not Started · In Progress · Blocked · Ready for Review · Done
```

## ملاحظة عن الـStarter

بعض المهام لها أساس موجود في الـStarter الحالي (مذكور تحت المهمة). هذا لا يعني
أنها منتهية — الحالة يحدّدها قائد الفريق.
