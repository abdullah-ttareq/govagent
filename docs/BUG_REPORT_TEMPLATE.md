# قالب تقرير خطأ — GovMind

انسخ القالب أدناه في تقرير جديد واملأه. **الحقول الخمسة الأولى إلزامية**:
تقريرٌ بلا خطوات إعادة إنتاج لا يُصلَح، ويُعاد إلى صاحبه.

> **لا تضع في التقرير أي كلمة مرور حقيقية ولا بيانات حكومية حقيقية.** إن
> ظهر رمز دخول في لقطة الشاشة فاطمسه.

---

## قبل أن ترفع التقرير

| الفحص | لماذا |
| ----- | ----- |
| هل الـBackend يعمل؟ | <http://localhost:8000/health> — أكثر «الأعطال» سيرفر متوقّف |
| هل رابط السيرفر صحيح في الإعدادات؟ | رابط خاطئ يعطي رسالة الاتصال نفسها |
| هل جرّبته بمتصفح ثانٍ؟ | يفصل خلل المتصفح عن خلل النظام |
| هل جرّبته بحساب آخر؟ | يفصل مشكلة الصلاحيات عن مشكلة الوظيفة |
| هل أعدت تشغيل الـBackend؟ | مخزن الذاكرة يفرغ، وقد تكون البيانات المتوقَّعة ذهبت |

## ما ليس خطأً

هذه سلوكيات **مقصودة** — لا تُرفع كأخطاء:

| السلوك | السبب |
| ------ | ----- |
| المحادثات تختفي بعد إعادة تشغيل الـBackend | `DATA_STORE=memory` غير دائم بالتصميم |
| مسار تجهيز الجهة يعيد **503** | `PROVISIONING_KEY` فارغ — يعطّل المسار عمدًا ولا يفتحه |
| سجل جهة أخرى يعيد **404 لا 403** | «ممنوع» تؤكد وجود السجل، وهذه معلومة عن جهة أخرى |
| مسؤول الجهة لا يرى محادثات موظفيه | المحادثة خاصة بصاحبها لا بجهته |
| الرد لا يجيب فعلًا عن السؤال | المزود `mock` تجريبي بلا مودل حقيقي |
| `/health` يعرض `oracle: not_configured` | حقل إعلامي؛ النظام يعمل بلا قاعدة |
| بعد تحديث الصفحة لا تُعاد المحادثة المختارة | تبقى في القائمة وتُستعاد باختيارها — مسجّل كتحسين لا عطل |
| الحساب المعطّل لا يسجّل الدخول | `s.alzahrani@urban-planning.test` معطّل عمدًا في البذرة |

## مثال مُعبّأ

```markdown
### العنوان
تغيير رابط السيرفر في الإضافة لا يُحفظ رغم الضغط على «حفظ الرابط»

### الأهمية
- [x] متوسطة

### خطوات إعادة الإنتاج
1. افتح نافذة الإضافة واضغط «الإعدادات».
2. اكتب http://192.168.1.20:8000
3. اضغط «حفظ الرابط».

### النتيجة المتوقعة
يُحفظ الرابط وتظهر «تم حفظ الرابط».

### النتيجة الفعلية
تظهر «لم يُمنح إذن الاتصال بهذا الرابط، فلم يُحفظ.» ولم تظهر نافذة إذن.

### البيئة
- المكوّن: الإضافة
- المتصفح: Chrome 151
- نظام التشغيل: Windows 11
- الجهاز: مكتبي — جهاز حقيقي
- الحساب: n.alharbi@digital-services.test
- MODEL_PROVIDER: mock · DATA_STORE: memory

### الأدلة
- وحدة التحكّم: "This function must be called during a user gesture"

### التكرار
- [x] يتكرر في كل مرة

### ملاحظات
يحدث حين يُستدعى الحفظ برمجيًا لا بنقرة حقيقية؛ إذن النطاق يشترط نقرة
مستخدم. بالنقر اليدوي يعمل.
```
