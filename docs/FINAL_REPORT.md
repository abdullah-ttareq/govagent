## ٤. الأخطاء والقيود المعروفة المتبقية

### أ) اكتُشف أثناء اختبار التكامل

**تعارض `localhost` مع `127.0.0.1` في CORS.** فتح الواجهة على
`http://127.0.0.1:3000` بينما `FRONTEND_URL=http://localhost:3000` يعطي
المستخدم رسالة مضللة: «تعذّر الاتصال بسيرفر الجهة. تأكد من تشغيل الـBackend»،
بينما الـBackend يعمل والسبب الحقيقي حجب CORS.

- **الأثر:** إرباك للمشغّل، لا خلل وظيفي. المسار الموثّق (`localhost:3000`)
  يعمل بلا مشكلة، وقد جُرِّب في متصفح حقيقي.
- **الحل المقترح (لم يُنفَّذ، خارج نطاق هذه المهمة):** إضافة نظير
  `127.0.0.1` تلقائيًا إلى `allow_origins`، أو تحسين رسالة الخطأ في الواجهة
  لتذكر احتمال CORS.

### ب) قيود مقصودة في نسخة الأسبوع

| القيد | الأثر |
|---|---|
| المخزن المحلي `memory` غير دائم | يفرغ عند إعادة تشغيل الـBackend، ولا يصلح لأكثر من عملية |
| المتجهات المحلية قائمة على الكلمات | لا تحل الضمائر: «وما بنودها؟» لا تسترجع. مزود OCI يتجاوز ذلك |
| لا مسار HTTP لرفع الملفات | المعالجة عبر دوال الخدمة فقط. المسار من حصة الشخص الثاني |
| PDF بلا طبقة نصية | يُرفض برسالة واضحة. لا OCR |
| `updated_at` لا يُحدَّث تلقائيًا | مسؤولية الـBackend. لا Trigger عمدًا |
| الحاويات بمستخدم `root` | لا `HEALTHCHECK` ولا حدود موارد ولا TLS |

### ج) ما لم يُختبر إطلاقًا — ولا يُدّعى اختباره

- **Oracle:** لا اتصال حي، ولا تشغيل لـ`schema.sql`، ولا `VECTOR_DISTANCE`
  فعلي، ولا قبول عمود `VECTOR` لمتجه. المخطط رُوجع **مراجعة ثابتة فقط**.
- **OCI Generative AI:** لا استدعاء حي للمحادثة ولا للمتجهات.
- **Docker:** لم يُنفَّذ `docker compose up` ولا بُنيت أي صورة. المتحقَّق منه:
  صلاحية `docker-compose.yml` نحويًا، ونجاح `npm run build`، وعمل أمر تشغيل
  الواجهة كما هو في الـDockerfile.
- **الإضافة داخل Chrome:** لم تُحمَّل فعليًا. المتحقَّق منه: طلبها بنفس شكله
  يعيد `200` بترويسة CORS صحيحة، وحقلا `reply` و `provider` اللذان تقرؤهما
  ما زالا موجودين.
- **مسار كامل من تسجيل الدخول:** غير ممكن — لا مصادقة بعد.
