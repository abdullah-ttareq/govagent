# PERSON_3 — واجهة الويب (Web Frontend)

**عدد المهام: ٥**

## P3-01 — نظام التصميم و RTL وصفحة الدخول

### وش تسوي؟

تجهيز أساس الواجهة العربية، مع دعم RTL، ونظام تصميم موحّد، وصفحة تسجيل دخول وحماية الصفحات للمستخدمين المسجلين.

### الخطة

1. إنشاء نظام تصميم للألوان والخطوط والمسافات والأزرار والحقول.
2. تطبيق RTL واللغة العربية على كامل الواجهة.
3. اختيار خط عربي واضح ومناسب.
4. إنشاء صفحة تسجيل الدخول بالبريد وكلمة المرور.
5. حفظ الـToken وحماية الصفحات التي تتطلب تسجيل الدخول.

---

## P3-02 — واجهة الشات والمحادثات

### وش تسوي؟

بناء واجهة المحادثة الرئيسية التي تتيح للموظف إرسال الرسائل والتعامل مع المحادثات من خلال الشريط الجانبي.

### الخطة

1. إنشاء واجهة رسائل واضحة بين المستخدم والإيجنت.
2. دعم الكتابة متعددة الأسطر والإرسال باستخدام Enter.
3. إضافة التمرير التلقائي لآخر رسالة.
4. إنشاء Sidebar للمحادثات مع تمييز المحادثة الحالية.
5. إضافة إنشاء محادثة وإعادة تسميتها وحذفها.
6. دعم الواجهة على الشاشات الصغيرة.

---

## P3-03 — رفع الملفات والأخطاء والإعدادات

### وش تسوي؟

إضافة إمكانية رفع الملفات داخل النظام، وإظهار حالات التحميل والأخطاء، مع صفحة لإعدادات رابط السيرفر.

### الخطة

1. إضافة رفع الملفات بالسحب والإفلات أو اختيار الملف.
2. عرض اسم الملف وحجمه وحالة الرفع.
3. التحقق من نوع وحجم الملف قبل رفعه.
4. إضافة حالات التحميل والانتظار.
5. عرض رسائل أخطاء عربية واضحة مع إمكانية إعادة المحاولة.
6. إنشاء صفحة لإعداد رابط سيرفر الجهة واختبار الاتصال.

---

## P3-04 — لوحة مسؤول الجهة

### وش تسوي؟

إنشاء لوحة خاصة بمسؤول الجهة لإدارة الموظفين ومتابعة الاشتراك والتراخيص وسجل العمليات.

### الخطة

1. إنشاء لوحة محمية لمسؤول الجهة فقط.
2. عرض الموظفين وإضافة الموظفين وتعطيلهم وتغيير أدوارهم.
3. عرض حالة الاشتراك وعدد المقاعد وتاريخ الانتهاء.
4. إضافة تنبيهات عند قرب انتهاء الاشتراك أو اكتمال المقاعد.
5. عرض سجل التدقيق مع إمكانية التصفية والترقيم.
6. إضافة حالات واضحة عند عدم وجود بيانات أو حدوث خطأ.

---

## P3-05 — ربط الـAPIs و PWA والتجاوب النهائي

### وش تسوي؟

ربط الواجهة بالكامل بالـBackend، وتحسين تجربة الاستخدام على الجوال والكمبيوتر، وتحويل النظام إلى PWA قابل للتثبيت.

### الخطة

1. ربط جميع صفحات الواجهة بالـAPIs الحقيقية.
2. إرسال الـJWT مع الطلبات المحمية والتعامل مع انتهاء الجلسة.
3. إضافة PWA مع Manifest وService Worker والأيقونات.
4. تحسين التجاوب للجوال واللوحي والمكتبي.
5. تحويل الشريط الجانبي إلى قائمة منزلقة على الجوال.
6. تحسين التباين والتركيز والتنقل ولوحة المفاتيح.
7. التأكد من أن المسار الكامل يعمل من تسجيل الدخول حتى تسجيل الخروج.
