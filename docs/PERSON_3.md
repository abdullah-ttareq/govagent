# P3-01 — نظام التصميم و RTL وصفحة الدخول

- **الحالة:** Not Started
- **تعتمد على:** لا شيء
- **الملفات المتوقعة:** `frontend/app/` · `frontend/components/` ·
  `frontend/app/globals.css`

## ما تشمله

1. **نظام تصميم بسيط:** ألوان وخطوط ومسافات وأحجام نص كمتغيرات CSS، وأزرار
   وحقول إدخال ورسائل موحّدة.
2. تثبيت **RTL** في كل الواجهة: `dir="rtl"` و `lang="ar"`، ومحاذاة وأيقونات
   صحيحة الاتجاه.
3. خط عربي واضح ومقروء على الشاشات الصغيرة.
4. **صفحة تسجيل الدخول:** حقل بريد وكلمة مرور، وتحقق أولي في الواجهة، وحالة
   إرسال، ورسالة خطأ عربية واضحة عند فشل الدخول.
5. حفظ الـToken وحماية الصفحات: غير المسجَّل يُحوَّل إلى صفحة الدخول.

## شرط الإنجاز

- الواجهة كلها RTL بلا نص مقلوب أو محاذاة خاطئة.
- زيارة صفحة محمية بلا تسجيل دخول تُحوِّل إلى `/login`.

```
اقرأ docs/PERSON_3.md.
نفّذ المهمة P3-01. تأكد من أنك داخل C:\Users\abdul\govagent-repo عبر
git rev-parse --show-toplevel قبل أي تعديل.
افحص frontend/ كاملًا قبل التعديل. لا تعِد إنشاء المشروع ولا تبدّل إطار العمل.
لا تعمل Commit أو Push أو Merge، ولا تنشئ فروعًا أو Issues.

المطلوب:
1. أنشئ نظام تصميم بسيطًا: ألوان وخطوط ومسافات وأحجام نص كمتغيرات CSS، مع
   أزرار وحقول إدخال ورسائل موحّدة قابلة لإعادة الاستخدام.
2. ثبّت RTL في كل الواجهة: dir="rtl" و lang="ar"، ومحاذاة واتجاه أيقونات صحيح.
3. اختر خطًا عربيًا واضحًا ومقروءًا على الشاشات الصغيرة.
4. أنشئ صفحة تسجيل دخول: بريد وكلمة مرور، تحقق أولي في الواجهة، حالة إرسال،
   ورسالة خطأ عربية واضحة عند الفشل.
5. احفظ الـToken بعد الدخول، واحمِ الصفحات: غير المسجَّل يُحوَّل إلى /login.
إن لم يكن مسار تسجيل الدخول جاهزًا في الـBackend، اعمل على بيانات تجريبية
واترك نقطة الربط واضحة.

شغّل: cd frontend && npm run build
في النهاية اذكر الملفات المعدّلة ونتيجة البناء كما ظهرت فعلًا.
```

# P3-02 — واجهة الشات والمحادثات

- **الحالة:** Not Started
- **تعتمد على:** P3-01
- **الملفات المتوقعة:** `frontend/app/` · `frontend/components/` ·
  `frontend/lib/`

## ما تشمله

1. **واجهة الشات:** قائمة رسائل تفرّق بصريًا بين رسالة المستخدم ورد الإيجنت،
   وحقل إدخال متعدد الأسطر، وإرسال بـ`Enter` وسطر جديد بـ`Shift+Enter`.
2. تمرير تلقائي إلى آخر رسالة، ونص طويل يلتف بلا كسر التخطيط.
3. **الشريط الجانبي (Sidebar):** قائمة المحادثات، والمحادثة النشطة مميّزة،
   وقابل للطي على الشاشات الصغيرة.
4. **إنشاء محادثة جديدة، وإعادة تسميتها، وحذفها** مع تأكيد قبل الحذف
   (تأكيد داخل الواجهة، لا `confirm()` المتصفح).
5. حالة فارغة واضحة عند عدم وجود محادثات.

## شرط الإنجاز

- إرسال رسالة يعرض رد الإيجنت في نفس المحادثة.
- إنشاء وإعادة تسمية وحذف محادثة تعمل وتنعكس في الشريط الجانبي فورًا.

```
اقرأ docs/PERSON_3.md.
نفّذ المهمة P3-02. تأكد من أنك داخل C:\Users\abdul\govagent-repo عبر
git rev-parse --show-toplevel قبل أي تعديل.
لا تعمل Commit أو Push أو Merge، ولا تنشئ فروعًا أو Issues.

المطلوب:
1. طوّر واجهة الشات: قائمة رسائل تفرّق بصريًا بين رسالة المستخدم ورد الإيجنت،
   وحقل إدخال متعدد الأسطر، وإرسال بـEnter وسطر جديد بـShift+Enter.
2. أضف تمريرًا تلقائيًا إلى آخر رسالة، واجعل النص الطويل يلتف بلا كسر التخطيط.
3. طوّر الشريط الجانبي: قائمة المحادثات، تمييز المحادثة النشطة، وقابلية الطي
   على الشاشات الصغيرة.
4. أضف إنشاء محادثة جديدة وإعادة تسميتها وحذفها، مع تأكيد للحذف داخل الواجهة
   وليس عبر confirm() المتصفح.
5. أضف حالة فارغة واضحة عند عدم وجود محادثات.

شغّل: cd frontend && npm run build
في النهاية اذكر الملفات المعدّلة ونتيجة البناء كما ظهرت فعلًا.
```

# P3-03 — رفع الملفات وحالات التحميل والأخطاء والإعدادات

- **الحالة:** Not Started
- **تعتمد على:** P3-02
- **الملفات المتوقعة:** `frontend/components/` · `frontend/lib/api.ts` ·
  `frontend/app/`

## ما تشمله

1. **رفع الملفات:** زر رفع وسحب وإفلات، وعرض اسم الملف وحجمه، ومؤشر تقدم،
   وإمكانية الإزالة قبل الإرسال.
2. تحقق في الواجهة من الامتداد والحجم قبل الإرسال، برسالة عربية واضحة.
3. **حالات التحميل:** مؤشر أثناء انتظار الرد، وتعطيل زر الإرسال، وهيكل
   تحميل (Skeleton) لقائمة المحادثات.
4. **معالجة الأخطاء:** رسالة عربية واضحة لكل حالة (السيرفر متوقف، الجلسة
   منتهية، الاشتراك منتهٍ، المزود غير متاح، خطأ عام) مع زر إعادة محاولة.
5. **صفحة إعدادات رابط السيرفر:** الموظف يضبط عنوان سيرفر جهته، ويُحفظ محليًا،
   ويُستخدم في كل الطلبات، مع زر اختبار اتصال يفحص `/health`.

## شرط الإنجاز

- إيقاف الـBackend يعطي رسالة عربية واضحة لا شاشة بيضاء ولا خطأ في الـConsole.
- تغيير رابط السيرفر ينعكس على كل الطلبات بعد الحفظ.

```
لا تعمل Commit أو Push أو Merge، ولا تنشئ فروعًا أو Issues.

المطلوب:
1. أضف رفع الملفات: زر رفع وسحب وإفلات، وعرض الاسم والحجم، ومؤشر تقدم،
   وإمكانية الإزالة قبل الإرسال.
```

# P3-04 — لوحة مسؤول الجهة

- **الحالة:** Not Started
- **تعتمد على:** P3-01
- **الملفات المتوقعة:** `frontend/app/` · `frontend/components/`

## ما تشمله

1. **لوحة المسؤول:** صفحة محمية بالدور `admin` فقط، والموظف العادي لا يراها
   ولا يصل إليها برابط مباشر.
2. **إدارة الموظفين:** قائمة، وإضافة، وتعطيل، وحذف، وتغيير الدور، مع تأكيد
   داخل الواجهة قبل أي إجراء مدمّر.
3. **عرض الاشتراك والتراخيص:** تاريخ الانتهاء، وعدد المقاعد المستخدمة من
   الإجمالي، وتنبيه واضح عند الاقتراب من الانتهاء أو تجاوز المقاعد.
4. **سجل التدقيق (Audit Logs):** جدول بالأحداث مع الوقت والمستخدم والنوع،
   وفلترة بالتاريخ والنوع، وترقيم الصفحات.
5. حالات فارغة وحالات خطأ لكل قسم.

## شرط الإنجاز

- موظف عادي يفتح رابط اللوحة يُمنع برسالة واضحة.
- الأرقام المعروضة (المقاعد، تاريخ الانتهاء) تأتي من الـAPI لا ثابتة في الكود.

```

المطلوب:
```

# P3-05 — ربط الـAPIs و PWA والتجاوب النهائي

- **الحالة:** Not Started
- **تعتمد على:** P3-02 · P3-03 · P3-04 · وعمل PERSON_2
- **الملفات المتوقعة:** `frontend/lib/api.ts` · `frontend/app/` ·
  `frontend/public/`

## ما تشمله

1. **ربط كل الواجهة بالـAPIs الحقيقية** وإزالة البيانات التجريبية المؤقتة من
   المسارات التي صار لها API فعلي.
2. إرسال الـJWT في كل طلب محمي، والتعامل مع انتهاء الجلسة بتحويل إلى الدخول.
3. **PWA:** ملف `manifest` وأيقونات و`Service Worker` بسيط، بحيث يظهر خيار
   «تثبيت التطبيق» ويعمل بعد التثبيت.
4. **التجاوب (Responsive):** جوال ولوحي ومكتبي، والشريط الجانبي يتحول إلى
   قائمة منزلقة على الجوال.
5. **الصقل النهائي:** تباين ألوان مقبول، وتركيز لوحة مفاتيح واضح، وعناوين
   صفحات، وتنظيف تحذيرات الـConsole.

## شرط الإنجاز

- مسار كامل يعمل: دخول ← محادثة ← رسالة ← رد ← تسجيل خروج.
- خيار التثبيت يظهر في Chrome، والواجهة سليمة على عرض ٣٦٠ بكسل.

```
اقرأ docs/PERSON_3.md.
نفّذ المهمة P3-05. تأكد من أنك داخل C:\Users\abdul\govagent-repo عبر
git rev-parse --show-toplevel قبل أي تعديل.
لا تعمل Commit أو Push أو Merge، ولا تنشئ فروعًا أو Issues.

المطلوب:
1. اربط كل الواجهة بالـAPIs الحقيقية، وأزل البيانات التجريبية من كل مسار صار
   له API فعلي. أبقِ ما لا API له، واذكره صراحة في تقريرك.
2. أرسل الـJWT في كل طلب محمي، وعالج انتهاء الجلسة بتحويل المستخدم إلى صفحة
   الدخول برسالة واضحة.
3. فعّل PWA: manifest وأيقونات وService Worker بسيط، بحيث يظهر خيار تثبيت
   التطبيق ويعمل بعد التثبيت.
4. اضبط التجاوب على الجوال واللوحي والمكتبي، واجعل الشريط الجانبي قائمة
   منزلقة على الجوال.
5. اصقل النهائيات: تباين ألوان مقبول، تركيز لوحة مفاتيح واضح، عناوين صفحات،
   وتنظيف تحذيرات الـConsole.

شغّل: cd frontend && npm run build
في النهاية اذكر الملفات المعدّلة ونتيجة البناء كما ظهرت فعلًا، وما جرّبته
يدويًا وما لم تجرّبه.
```
