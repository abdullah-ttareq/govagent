# PERSON_4 — إضافة المتصفح والاختبار والتوثيق

**عدد المهام: ٤**

## P4-01 — تطوير إضافة المتصفح

### وش تسوي؟

تطوير إضافة المتصفح بحيث تتيح للموظف تسجيل الدخول واستخدام المساعد وإدارة المحادثات، مع دعم الحالات المختلفة والأمان الأساسي.

### الخطة

1. إضافة تسجيل الدخول والخروج وحفظ الـToken.
2. ربط الإضافة بالـBackend وإرسال الـToken مع الطلبات.
3. عرض سجل المحادثة والردود السابقة.
4. إضافة إنشاء محادثة جديدة والاحتفاظ بآخر محادثة.
5. إضافة رسائل واضحة لحالات الخطأ مثل انتهاء الجلسة أو الاشتراك أو توقف السيرفر.
6. تحسين تصميم الإضافة ودعم لوحة المفاتيح.

## P4-02 — البيانات التجريبية وPostman

### وش تسوي؟

تجهيز بيانات تجريبية تساعد الفريق على تجربة النظام، وإنشاء مجموعة Postman لاختبار جميع وظائف الـBackend.

### الخطة

1. إنشاء بيانات تجريبية لعدة جهات ومستخدمين بأدوار واشتراكات مختلفة.
2. إضافة محادثات ورسائل وملفات تجريبية متنوعة.
3. التأكد من عدم استخدام أي بيانات أو أسرار حقيقية.
4. إنشاء مجموعة Postman تغطي أهم مسارات النظام.
5. إعداد متغيرات مثل `base_url` و`token` لتسهيل تشغيل الطلبات.
6. إضافة طلبات لاختبار حالات النجاح والأخطاء.

## P4-03 — حالات الاختبار الآلية

### وش تسوي؟

إنشاء اختبارات آلية للتأكد من صحة النظام، خصوصًا المصادقة والاشتراكات وعزل بيانات الجهات ورفع الملفات.

### الخطة

1. اختبار صحة الخدمة والمحادثة.
2. اختبار تسجيل الدخول وحالات الـToken المختلفة.
3. اختبار الاشتراكات المنتهية والسارية.
4. اختبار عزل بيانات الجهات ومنع الوصول لبيانات جهة أخرى.
5. اختبار رفع الملفات والامتدادات والأحجام.
6. إضافة اختبارات للحالات الحرجة في الـBackend.
7. توضيح الاختبارات التي تحتاج Oracle بدل اعتبارها فاشلة.

## P4-04 — الفحص اليدوي والتوثيق النهائي

### وش تسوي؟

التأكد من أن النظام يعمل بشكل متكامل، وتجهيز التوثيق النهائي وطريقة تشغيل المشروع وعرضه.

### الخطة

1. إعداد قائمة فحص تشمل تسجيل الدخول والمحادثات والملفات والإعدادات ولوحة المسؤول.
2. فحص الواجهة على الجوال واللوحي والكمبيوتر.
3. إعداد دليل لتشغيل المشروع من البداية.
4. إعداد طريقة تحميل وتشغيل إضافة المتصفح.
5. تجهيز سيناريو مختصر لعرض المشروع.
6. إعداد قالب لتسجيل الأخطاء والمشاكل.
7. تحديث ملفات التوثيق وREADME بالمعلومات النهائية.
