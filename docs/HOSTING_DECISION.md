# قرار الاستضافة

> **التوصية:** تشغيل التطبيق وقاعدة البيانات على سيرفر الجهة، مع إمكانية استخدام مودل محلي حسب إمكانيات الجهة.

---

## الخلاصة

**التوصية: سيرفر الجهة (On-Premise)**

| الخيار                 | التطبيق   | قاعدة البيانات    | المودل              |
| ---------------------- | --------- | ----------------- | ------------------- |
| **سيرفر الجهة** ✅      | نعم       | Oracle داخل الجهة | `mock` أو مودل محلي |
| **سيرفر محلي للتجربة** | نعم       | حسب الإعداد       | `mock` أو مودل محلي |
| **VPS تجاري**          | للعرض فقط | حسب الإعداد       | `mock` أو مودل محلي |

---

## ١. سيرفر الجهة — التوصية

**لماذا:**

* بيانات النظام تبقى داخل بيئة الجهة.
* المشروع قابل للتشغيل على سيرفر الجهة باستخدام Docker.
* يمكن تشغيل النظام محليًا بدون الاعتماد على خدمات خارجية.
* الجهة تتحكم في بياناتها ونسخها الاحتياطية وصلاحيات الوصول إليها.
* يمكن استخدام مودل محلي حسب إمكانيات السيرفر.

**التكلفة:** سيرفر واحد داخل الجهة، بالإضافة إلى تكلفة التجهيز والصيانة حسب بيئة الجهة.

**ما تحتاجه الجهة:**

* Docker
* قاعدة بيانات Oracle عند الحاجة
* مساحة تخزين مناسبة للملفات
* موارد كافية لتشغيل المودل المحلي إذا تم استخدامه

**العيب المقبول:** تشغيل مودل حقيقي محليًا قد يحتاج إلى عتاد قوي، خصوصًا عند استخدام مودلات كبيرة.

---

## ٢. التشغيل المحلي

يمكن تشغيل المشروع على جهاز تطوير أو سيرفر داخلي لأغراض التجربة والعرض.

الإعداد الافتراضي يستخدم:

```env
MODEL_PROVIDER=mock
RETRIEVAL_PROVIDER=memory
```

وهذا يسمح بتجربة النظام بدون الحاجة إلى إعداد خدمات خارجية.

كما يمكن استخدام مودل محلي من خلال LM Studio عند الحاجة إلى إجابات فعلية.

---

## ٣. VPS تجاري

يُستخدم كبيئة مؤقتة للعرض والتجربة فقط.

يجب استخدام بيانات تجريبية وعدم وضع أي بيانات حكومية أو بيانات اعتماد حقيقية عليه.

---

## ٤. خطة التنفيذ الموصى بها

1. **العرض والمناقشة:** تشغيل النظام على جهاز محلي أو بيئة مؤقتة باستخدام `mock` وبيانات تجريبية.
2. **التجربة داخل الجهة:** تشغيل النظام على سيرفر الجهة باستخدام Docker وقاعدة البيانات المناسبة.
3. **التشغيل الفعلي:** تفعيل المصادقة، وتأمين الاتصال، وإعداد النسخ الاحتياطي، وتجهيز المراقبة والصيانة.

---

## ٥. حدود هذه التوصية

* التوصية مبنية على معمارية المشروع ومتطلبات التشغيل المتوقعة.
* اختيار العتاد المناسب يعتمد على عدد المستخدمين وحجم البيانات وحجم المودل المستخدم.
* يجب اختبار الأداء قبل التشغيل الفعلي لتحديد موارد السيرفر المطلوبة.
* يجب على الجهة تحديد سياسات حفظ البيانات والنسخ الاحتياطي والصلاحيات قبل اعتماد بيئة التشغيل.
