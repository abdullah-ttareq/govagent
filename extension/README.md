# GovMind — إضافة المتصفح

نافذة عربية RTL تسجّل الدخول إلى سيرفر جهتك، وتعرض سجل المحادثة، وتحتفظ بآخر
محادثة بعد إغلاقها.

**Manifest V3 · HTML + CSS + JavaScript مباشر · بلا React وبلا Build System.**

---

## ما تفعله وما لا تفعله

تفعل:

- **تسجيل دخول وخروج** من داخل النافذة عبر `/api/auth/login` و `/api/auth/me`
  و `/api/auth/logout`.
- تحفظ رمز الدخول في `chrome.storage.local` وترسله في كل طلب محمي بترويسة
  `Authorization: Bearer <token>`.
- **تعرض سجل المحادثة كاملًا** لا ردًّا واحدًا، مع تمرير تلقائي إلى الأسفل.
- **تحتفظ بآخر محادثة**: تحفظ معرّفها، وتعيد بناء الرسائل من السيرفر عند كل
  فتح.
- زر **«محادثة جديدة»** يترك السابقة محفوظة على السيرفر ويبدأ غيرها.
- رسالة عربية وإجراء مقترح لكل حالة فشل: جلسة منتهية، اشتراك منتهٍ، سيرفر
  متوقف، إذن نطاق غير ممنوح.
- تحفظ رابط السيرفر (API Base URL) وتسمح بتغييره من داخل النافذة.
- **وضع فاتح وداكن** بثلاثة خيارات (فاتح · داكن · الجهاز)، يبقى الاختيار
  بعد إغلاق النافذة، ويعمل في النافذة المنبثقة والتبويب الكامل معًا.

لا تفعل:

- **لا تستخدم Content Scripts** — صفر، ويثبته `manifest.json`.
- **لا تطلب أي صلاحية لقراءة صفحات المستخدم** (لا `activeTab` ولا `tabs` ولا
  `scripting`).
- **لا تحفظ نصّ أي محادثة على الجهاز**: المحفوظ محليًا أربعة مفاتيح فقط —
  `accessToken` و `tokenExpiresAt` و `conversationId` و `user` (اسم الموظف
  وبريده وجهته، لعرضها في الشريط السفلي)، ومعها `apiBaseUrl` إن غُيّر.
  **نصّ الرسائل يُقرأ من السيرفر عند كل فتح** ولا يُخزَّن.
- لا تجمع أي بيانات ولا ترسلها إلى أي جهة غير سيرفر الجهة الذي تضبطه أنت.

الصلاحيات المطلوبة:

| الصلاحية                                  | السبب                                     |
| ----------------------------------------- | ----------------------------------------- |
| `storage`                                 | حفظ الرمز وبيانات الموظف ومعرّف المحادثة ورابط السيرفر. |
| `host_permissions` لـ`localhost:8000`     | الاتصال بالـBackend أثناء التطوير.        |
| `optional_host_permissions`               | تُطلب فقط عند حفظ رابط سيرفر مختلف.       |

> **رمز الدخول في `chrome.storage.local`.** تخزين الإضافة معزول عن كل صفحة
> يفتحها الموظف، فلا تصل إليه سكربتات المواقع — والإضافة لا تقرأ أي صفحة
> أصلًا ولا تملك صلاحية لذلك. الرمز موقّع ومدته ثماني ساعات، ولا يُلغى على
> السيرفر عند الخروج (لا قائمة إبطال في الـMVP)، لذلك يُمسح من الجهاز فورًا.

## الملفات

```
extension/
├── manifest.json   إعداد Manifest V3 والأيقونات
├── popup.html      واجهة النافذة (RTL)
├── theme-init.js   يضبط المظهر قبل أول رسم — يمنع الوميض
├── popup.css       التنسيق — ارتفاع ثابت، وحاوية متوسطة في التبويب الكامل
├── popup.js        منطق الحالات والإرسال
├── lib/
│   ├── api.js      نداءات الـBackend وأخطاؤها
│   ├── storage.js  غلاف chrome.storage.local
│   └── errors.js   ترجمة كل فشل إلى رسالة عربية وإجراء
├── icons/          أيقونات 16 و32 و48 و128
└── README.md       هذا الملف
```

الملفات في `lib/` وحدات ES يحمّلها المتصفح مباشرة
(`<script type="module">`) — **لا Bundler ولا خطوة بناء**.

## المسارات المستخدمة

كلها موجودة فعلًا في الـBackend، ولا يخترع الملحق مسارًا:

| المسار                                   | الاستخدام                        |
| ---------------------------------------- | -------------------------------- |
| `POST /api/auth/login`                   | تسجيل الدخول وإصدار الرمز        |
| `GET /api/auth/me`                       | التحقق من الجلسة عند فتح النافذة |
| `POST /api/auth/logout`                  | تسجيل الخروج                     |
| `POST /api/chat`                         | إرسال رسالة واستقبال الرد        |
| `GET /api/conversations/{id}/messages`   | استعادة سجل آخر محادثة           |

**كل طلب يحمل رمز الدخول.** `POST /api/chat` صار محميًا بالكامل منذ P4-03،
والطلب بلا رمز يعيد 401.

**ولا تُرسل الإضافة حقل `history`:** الحقل حُذف من الـAPI — السياق يُقرأ من
المحادثة المحفوظة على السيرفر، وسياقٌ يرسله العميل يمكن تلفيقه.

## التشغيل — Load unpacked

1. شغّل الـBackend أولًا:

   ```bash
   cd backend && .venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
   ```

   (على لينكس أو ماك استبدل `.venv/Scripts/` بـ`.venv/bin/`.)

   تأكد أنه يعمل: <http://localhost:8000/health>

2. افتح Chrome أو Edge على `chrome://extensions`.
3. فعّل **Developer mode** من أعلى يمين الصفحة.
4. اضغط **Load unpacked**.
5. اختر مجلد `extension` من هذا المستودع (المجلد نفسه، وليس ملف
   `manifest.json`).
6. ثبّت أيقونة GovMind من قائمة الإضافات، ثم اضغط عليها لفتح النافذة.
7. سجّل الدخول بأحد حسابات التطوير المذكورة في
   [`README.md`](../README.md#مستخدمو-التطوير) — مثلًا
   `n.alharbi@digital-services.test` بكلمة المرور `GovAgent@2026`.

بعد أي تعديل على ملفات الإضافة: ارجع إلى `chrome://extensions` واضغط **Reload**
على بطاقة GovMind، ثم أعد فتح النافذة.

## نافذة منبثقة أم تبويب كامل؟

| الحالة | ما يحدث |
| ------ | ------- |
| **الأيقونة في شريط الأدوات** | نافذة ٣٨٠×٥٦٠ — المقاس المصمَّمة له |
| **`chrome-extension://<id>/popup.html` في تبويب** | حاوية بعرض ٦٤٠ **متوسّطة أفقيًا** وتملأ الارتفاع |

كان المحتوى في التبويب الكامل يلتصق بحافة البداية (اليمين في RTL) ويترك
فراغًا أبيض شاسعًا. الآن يتوسّط. الاستعلام `@media (min-width: 480px)` لا
يتحقق في النافذة المنبثقة إطلاقًا، لأن عرضها يساوي عرض الجسم تمامًا.

**النص المختلط عربي/إنجليزي** في الرسائل وحقل الكتابة يُعالَج بـ
`unicode-bidi: plaintext`: كل فقرة تأخذ اتجاهها من أول حرف قويّ فيها، فلا
تنقلب جملة إنجليزية داخل رد عربي ولا يهاجر ترقيمها إلى الطرف الخطأ.

## الوضع الفاتح والداكن

ثلاثة أزرار في رأس النافذة: **فاتح · داكن · الجهاز**. الافتراضي «الجهاز»،
فتتبع الإضافة إعداد النظام في أول فتح، ثم يبقى اختيار الموظف بعده.

**الاختيار في `localStorage` لا في `chrome.storage.local`** — ولا يحتاج
أيٌّ منهما صلاحية جديدة، **ولم يتغيّر `manifest.json`**. السبب أن قراءة
`localStorage` **متزامنة**، فيضبط [`theme-init.js`](theme-init.js) الوضع
قبل أول رسم؛ أما `chrome.storage.local` فغير متزامن، فتُرسم النافذة
بالوضع الخطأ ثم تقفز — وهو الوميض نفسه الذي نتجنّبه.

السكربت ملف منفصل لا وسمٌ سطري: سياسة المحتوى في Manifest V3 تمنع
السكربت السطري في صفحات الإضافة.

الوضع الداكن **درجات كحلية داكنة لا أسود**، والأزرق الملكي يفتحّ إلى
`#6b9bff` ليبقى مقروءًا، ونصّ الأزرار فوقه يصير كحليًّا داكنًا. الأخضر
محجوز لحالات النجاح وحدها.

## تغيير رابط السيرفر

الرابط الافتراضي هو `http://localhost:8000`.

1. افتح النافذة واضغط **الإعدادات**.
2. اكتب الرابط الجديد (مثال: `http://192.168.1.20:8000`).
3. اضغط **حفظ الرابط**.
4. سيطلب المتصفح إذن الاتصال بذلك النطاق — وافق عليه، وإلا لن يُحفظ الرابط.

> **تغيير الرابط ينهي الجلسة عمدًا.** رمز الدخول صادر عن السيرفر القديم ولا
> يعرفه الجديد، فإبقاؤه يعطي 401 غامضة عند أول طلب. تُنهى الجلسة صراحةً
> وتظهر رسالة تشرح السبب.

## استكشاف الأخطاء

| ما يظهر                                  | السبب المتوقع والحل                                          |
| ---------------------------------------- | ------------------------------------------------------------ |
| «تعذّر الاتصال بـ…»                      | الـBackend غير مشغّل أو الرابط خطأ. الزر يفتح الإعدادات.      |
| «لم تمنح المتصفحَ إذنَ الاتصال بنطاق…»    | إذن النطاق غير ممنوح. الزر يطلبه من المتصفح.                  |
| «انتهت جلستك. سجّل الدخول من جديد.»       | الرمز انتهى أو لم يعد صالحًا. النافذة تعود لشاشة الدخول.       |
| «انتهى اشتراك جهتك بتاريخ …»             | اشتراك الجهة منتهٍ. **تبقى داخل الجلسة** — راجع مسؤول النظام. |
| «مزود المودل غير متاح حاليًا»            | `MODEL_PROVIDER` على مزود غير منفّذ. اضبطه على `mock`.        |
| «رد تجريبي — سيتم ربط مزود الذكاء…»      | ليس خطأ: المزود `mock` تجريبي بلا مودل حقيقي.                 |
| «لم تعد المحادثة السابقة موجودة»         | حُذفت المحادثة من تطبيق الويب. ابدأ محادثة جديدة.             |

الـBackend يسمح بطلبات الإضافة عبر CORS (`chrome-extension://…`). إذا استضافت
الجهة الـBackend خلف Proxy، تأكد أن الـProxy لا يحذف ترويسات CORS.

لقراءة أخطاء JavaScript: اضغط بزر الفأرة الأيمن داخل النافذة ثم **Inspect**.
