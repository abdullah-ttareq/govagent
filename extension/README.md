# GovAgent — إضافة المتصفح (Starter)

نافذة منبثقة عربية بسيطة تُرسل رسالة إلى GovAgent Backend وتعرض الرد.

**Manifest V3 · HTML + CSS + JavaScript مباشر · بلا React وبلا Build System.**

---

## ما تفعله وما لا تفعله

تفعل:

- تعرض حقل رسالة وزر إرسال.
- ترسل `POST {API_BASE_URL}/api/chat` بجسم `{"message": "..."}`.
- تعرض حالة التحميل، ورسالة خطأ واضحة عند الفشل، ورد الإيجنت عند النجاح.
- تحفظ رابط السيرفر (API Base URL) وتسمح بتغييره من داخل النافذة.

لا تفعل:

- **لا تستخدم Content Scripts.**
- **لا تطلب أي صلاحية لقراءة صفحات المستخدم** (لا `activeTab` ولا `tabs` ولا
  `scripting`).
- لا تجمع أي بيانات ولا ترسلها إلى أي جهة غير سيرفر الجهة الذي تضبطه أنت.

الصلاحيات المطلوبة:

| الصلاحية                                  | السبب                                     |
| ----------------------------------------- | ----------------------------------------- |
| `storage`                                 | حفظ رابط السيرفر محليًا.                  |
| `host_permissions` لـ`localhost:8000`     | الاتصال بالـBackend أثناء التطوير.        |
| `optional_host_permissions`               | تُطلب فقط عند حفظ رابط سيرفر مختلف.       |

## التشغيل — Load unpacked

1. شغّل الـBackend أولًا:

   ```bash
   cd backend && .venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
   ```

   (على لينكس أو ماك استبدل `.venv/Scripts/` بـ`.venv/bin/`.)

   تأكد أنه يعمل: <http://localhost:8000/health>

2. افتح Chrome أو Edge على `chrome://extensions`.
3. فعّل **Developer mode** من أعلى يمين الصفحة.
4. اضغط **Load unpacked**.
5. اختر مجلد `extension` من هذا المستودع (المجلد نفسه، وليس ملف
   `manifest.json`).
6. ثبّت أيقونة GovAgent من قائمة الإضافات، ثم اضغط عليها لفتح النافذة.

بعد أي تعديل على ملفات الإضافة: ارجع إلى `chrome://extensions` واضغط **Reload**
على بطاقة GovAgent، ثم أعد فتح النافذة.

## تغيير رابط السيرفر

الرابط الافتراضي هو `http://localhost:8000`.

1. افتح النافذة واضغط **الإعدادات**.
2. اكتب الرابط الجديد (مثال: `http://192.168.1.20:8000`).
3. اضغط **حفظ الرابط**.
4. سيطلب المتصفح إذن الاتصال بذلك النطاق — وافق عليه، وإلا لن يُحفظ الرابط.

## استكشاف الأخطاء

| ما يظهر                          | السبب المتوقع                                              |
| -------------------------------- | ---------------------------------------------------------- |
| «تعذّر الاتصال بـ…»              | الـBackend غير مشغّل، أو الرابط خطأ، أو الإذن غير ممنوح.    |
| «مزود المودل غير متاح حاليًا»    | `MODEL_PROVIDER` مضبوط على مزود غير منفّذ. اضبطه على `mock`. |
| «الرسالة غير مقبولة»             | الرسالة فارغة أو أطول من ٨٠٠٠ حرف.                          |

الـBackend يسمح بطلبات الإضافة عبر CORS (`chrome-extension://…`). إذا استضافت
الجهة الـBackend خلف Proxy، تأكد أن الـProxy لا يحذف ترويسات CORS.

لقراءة أخطاء JavaScript: اضغط بزر الفأرة الأيمن داخل النافذة ثم **Inspect**.
