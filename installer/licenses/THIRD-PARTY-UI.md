# حزم واجهة GovMind

الواجهة تصدير ساكن من Next.js، والحزم أدناه مدمجة في ملفات JavaScript
المرفقة في `{app}\ui`.

| الحزمة | الرخصة | الغرض |
|---|---|---|
| Next.js | MIT | إطار الواجهة والتصدير الساكن |
| React | MIT | بناء الواجهة |
| React DOM | MIT | الرسم في المتصفح |
| Tailwind CSS | MIT | الأنماط |

## التحديث

```bash
cd frontend
npx license-checker --production --summary
```

## ملاحظة

حقوق النشر. لا يوجد في الواجهة أي مكوّن بترخيص Copyleft.
