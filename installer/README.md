# مثبّت GovMind لويندوز

يبني ملفًا تنفيذيًا واحدًا يثبّت **GovMind Runtime** ومحرّك llama.cpp
وواجهة GovMind على جهاز العميل.

> **العميل لا يحتاج Python ولا Node.js ولا LM Studio.** المفسّر مجمَّع داخل
> `govmind-runtime.exe`، والواجهة تصدير ساكن، والمحرّك ثنائي رسمي.

---

## ١. البناء

```powershell
# مرة واحدة: ثنائيات llama.cpp الرسمية (رخصة MIT)
powershell -ExecutionPolicy Bypass -File installer\fetch-llama.ps1

# ثم البناء الكامل
powershell -ExecutionPolicy Bypass -File installer\build.ps1 `
    -ControlPlaneUrl "https://api.govmind.example"
```

المخرَج: `installer\output\GovMindSetup.exe`

### ما يفعله السكربت بالترتيب

| # | الخطوة | الأداة |
|---|---|---|
| ١ | تصدير واجهة GovMind ساكنًا | `npm run build` مع `GOVMIND_DESKTOP=1` |
| ٢ | تجميع الـRuntime في ملف تنفيذي | PyInstaller |
| ٣ | نسخ ثنائيات llama.cpp | من `runtime\vendor` |
| ٤ | كتابة الإعداد العام ونسخ التراخيص | — |
| ٥ | **فحص الحزمة من الأسرار** | يفشل البناء إن وُجد أي اسم سرّ |
| ٦ | بناء المثبّت | Inno Setup (`ISCC.exe`) |

### متطلبات جهاز البناء

| الأداة | مطلوبة لـ | التثبيت |
|---|---|---|
| Node.js 20+ | تصدير الواجهة | مثبَّت |
| Python 3.12+ | تجميع الـRuntime | مثبَّت |
| PyInstaller | تجميع الـRuntime | `pip install -r runtime\requirements.txt` |
| **Inno Setup 6** | **بناء المثبّت** | **⚠️ غير مثبَّت — انظر أدناه** |

---

## ٢. ⚠️ Inno Setup غير مثبَّت على جهاز التطوير الحالي

الخطوات ١–٥ تعمل كلها وتُنتج حزمة كاملة في `installer\staging`.
الخطوة ٦ وحدها متوقفة لغياب الأداة.

للتثبيت (أحد الأمرين، بصلاحيات مسؤول):

```powershell
winget install --id JRSoftware.InnoSetup -e
```

```powershell
choco install innosetup -y
```

ثم أعد تشغيل `build.ps1` — سيلتقط `ISCC.exe` تلقائيًا من مسار التثبيت
المعتاد ولا يحتاج ضبط `PATH`.

> **لم تُثبَّت الأداة تلقائيًا عمدًا:** تثبيت برنامج على جهاز المطوّر قرارٌ
> له، لا أثرٌ جانبي لأمر بناء.

---

## ٣. ⚠️ التوقيع الرقمي — لا توجد شهادة

المثبّت المُنتَج **غير موقّع**. عند تشغيله سيعرض ويندوز شاشة SmartScreen
زرقاء تقول **«Windows protected your PC»** وتذكر **«ناشر غير معروف»
(Unknown publisher)**، ويحتاج المستخدم الضغط على *More info* ثم
*Run anyway*.

**هذا سلوك صحيح لملف غير موقّع، ولا يُلتفّ عليه:**

- ❌ لا يُطلب من العميل تعطيل SmartScreen أو مكافح الفيروسات.
- ❌ لا يُستعمل أي أسلوب لإخفاء نافذة UAC أو تجاوزها.
- ❌ **لا يُقال إن هذا الإصدار جاهز للإنتاج.** ليس كذلك بلا توقيع.

### ما يلزم للإنتاج

1. **شهادة Code Signing** من مرجع معتمد. شهادة **EV** تعطي سمعة SmartScreen
   فورًا؛ الشهادة العادية تبني السمعة تدريجيًا وقد يظهر التحذير أسابيع.
2. توقيع **الملفين معًا** — الـRuntime والمثبّت:

```powershell
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 `
    installer\staging\govmind-runtime.exe

# ثم أعد بناء المثبّت ووقّعه
signtool sign /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 `
    installer\output\GovMindSetup.exe
```

الختم الزمني (`/tr`) ضروري: بدونه تبطل التوقيعات بانتهاء الشهادة.

## ٤. ما يُثبَّت وأين

```
C:\Program Files\GovMind\
├── govmind-runtime.exe      الخدمة المحلية
├── govmind.config.json      عنوان Backend — **قيمة عامة لا سرّ**
├── llama.cpp\               محرّك المودل (MIT)
├── ui\                      واجهة GovMind الثابتة
└── licenses\                تراخيص الأطراف الثالثة وشروط Gemma

C:\ProgramData\GovMind\
├── device.bin               هوية الجهاز — **محميّة بـDPAPI**
├── models\                  ملف المودل بعد تنزيله والتحقق منه
├── logs\                    سجلّ الـRuntime
└── session.txt              رمز الجلسة المحلي (يتغيّر عند كل إقلاع)
```

**التثبيت لكل الأجهزة (per-machine)** لأن هوية الجهاز والمودل يخصّان
الجهاز لا المستخدم — ويستدعي ذلك نافذة UAC، وهي مقصودة.

## ٥. ما لا يُحزَم في المثبّت

| العنصر | لماذا |
|---|---|
| **ملف المودل** (~٥٫٣ ج.ب) | يُنزَّل بعد التفعيل ويُتحقَّق منه بـSHA-256. حزمُه يجعل كل تحديث صغير يعيد تنزيله. |
| `SUPABASE_SERVICE_ROLE_KEY` | يتجاوز RLS. وجوده على جهاز عميل يُلغي عزل البيانات كله. |
| `AZURE_STORAGE_CONNECTION_STRING` | يحمل مفتاح حساب التخزين. |
| `DEVICE_HASH_PEPPER` | به تُجزّأ هويات كل الأجهزة. |
| `SUPABASE_JWT_SECRET` | به تُوقَّع رموز المستخدمين. |
| ثنائيات LM Studio | بناء خاص بها وغير مرخّص لإعادة التوزيع. |

الخطوة ٥ في `build.ps1` تفحص الحزمة وتُفشل البناء إن وجدت أيًّا من هذه
الأسماء — الفحص آلي لا اعتماد على الانتباه.

---

## ٦. إلغاء التثبيت

يوقف الخدمة، ويحذف ملفات البرنامج، **ويسأل** عن حذف المودل وهوية الجهاز.

- **الإبقاء عليهما** (الافتراضي): إعادة التثبيت لا تحتاج تنزيلًا ولا تفعيلًا.
- **الحذف**: يحتاج التثبيت التالي تنزيل المودل من جديد، **وقد يحتاج
  التفعيل إلغاء تفعيل الجهاز السابق من مسؤول النظام** — لأن السرّ القديم
  ضاع والقاعدة ما زالت تعدّ الجهاز مفعَّلًا.
