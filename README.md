# GovAgent

مساعد ذكاء اصطناعي عام لموظفي الجهات الحكومية. الجهة تثبّت النظام على سيرفرها،
ويتصل موظفوها بتطبيق ويب قابل للتثبيت كـPWA، أو بإضافة متصفح خفيفة.

جميع الموظفين يستخدمون نفس الإيجنت العام. الفرق بينهم في الحسابات والمحادثات
والملفات والصلاحيات فقط.

> **هذا مشروع تخرج في مرحلة MVP، وليس نظامًا جاهزًا للإنتاج.**
> لا تُستخدم فيه بيانات حكومية حقيقية ولا بيانات اعتماد حقيقية.

│   │   ├── core/      الإعدادات
│   │   ├── database/  طبقة Oracle (لم تُنفّذ بعد)

## متطلبات التشغيل

- Node.js 20 أو أحدث
- Python 3.11 أو أحدث
- متصفح Chrome أو Edge لتجربة الإضافة
- لا حاجة إلى Oracle ولا إلى بيانات اعتماد OCI لتشغيل الـStarter.

## الإعداد

انسخ ملف البيئة النموذجي:

```bash
cp .env.example .env
```

القيم الافتراضية كافية للتشغيل المحلي. اترك حقول Oracle و OCI فارغة.

## ١. تشغيل الـBackend

```bash
cd backend && python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
```

ثم:

```bash
cd backend && .venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
```

- فحص الحالة: <http://localhost:8000/health>
- توثيق Swagger: <http://localhost:8000/docs>

على لينكس أو ماك استبدل `.venv/Scripts/` بـ`.venv/bin/`.

الاختبارات:

```bash
cd backend && .venv/Scripts/python -m pytest
```

## ٢. تشغيل الـFrontend

```bash
cd frontend && npm install
```

ثم:

```bash
cd frontend && npm run dev
```

الواجهة على <http://localhost:3000>. شغّل الـBackend أولًا حتى تعمل المحادثة.

## ٣. قاعدة البيانات (Database)

مخطط Oracle في [`database/schema.sql`](database/schema.sql).

**لا يلزم تشغيل Oracle لتجربة المشروع.** الـStarter يعمل بالكامل بلا قاعدة
بيانات، والمحادثات لا تُحفظ. ربط Oracle وتشغيل المخطط ضمن مهمة **P1-02**.

## ٤. تشغيل الإضافة (Extension)

إضافة متصفح **Manifest V3** بـHTML و CSS و JavaScript مباشر — بلا React وبلا
Build System، وبلا Content Scripts، وبلا أي صلاحية لقراءة صفحات المستخدم.

1. شغّل الـBackend أولًا (الخطوة ١ أعلاه).
2. افتح `chrome://extensions` في Chrome أو Edge.
3. فعّل **Developer mode**.
4. اضغط **Load unpacked** واختر مجلد `extension`.
5. اضغط أيقونة GovAgent لفتح النافذة، واكتب رسالة واضغط إرسال.

رابط السيرفر الافتراضي `http://localhost:8000`، ويمكن تغييره من زر
**الإعدادات** داخل النافذة.

التفاصيل الكاملة في [`extension/README.md`](extension/README.md).

## مزود المودل

يُختار المزود من متغير واحد في `.env`:

| القيمة   | الوصف                                                   |
| -------- | ------------------------------------------------------- |
| `mock`   | **الافتراضي.** يعمل بلا Oracle ويعيد ردًا تجريبيًا واضحًا. |
| `oracle` | **اختياري** — OCI Generative AI، غير منفّذ بعد (مهمة P1-01). |
| `local`  | مودل داخل سيرفر الجهة — واجهة مستقبلية فقط.             |

```env
MODEL_PROVIDER=mock
```

**Mock Provider هو الافتراضي**، والمشروع يعمل به بالكامل بلا أي بيانات اعتماد.
**Oracle AI اختياري** ولا يحتاجه أي جزء من التشغيل المحلي.

القيمة غير المدعومة تُنتج رسالة خطأ واضحة تذكر القيم المقبولة.

## الاستضافة

**قرار الاستضافة لم يُحسم بعد.** الخيارات المطروحة: Oracle Cloud (OCI)، أو
VPS مستقل، أو سيرفر الجهة نفسها. المقارنة والتوصية النهائية ضمن مهمة **P1-06**.

## تحذير أمني

لا ترفع ملف `.env` ولا أي مفتاح أو بيانات اعتماد إلى المستودع.
`.env.example` فقط هو المسموح رفعه، ويجب أن يبقى بلا قيم حقيقية.
