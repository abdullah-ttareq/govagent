# GovAgent

مساعد ذكاء اصطناعي عام لموظفي الجهات الحكومية. الجهة تثبّت النظام على سيرفرها،
ويتصل موظفوها بتطبيق ويب قابل للتثبيت كـPWA.

جميع الموظفين يستخدمون نفس الإيجنت العام. الفرق بينهم في الحسابات والمحادثات
والملفات والصلاحيات فقط.

> **هذا مشروع تخرج في مرحلة MVP، وليس نظامًا جاهزًا للإنتاج.**
> لا تُستخدم فيه بيانات حكومية حقيقية ولا بيانات اعتماد حقيقية.

---

## هيكل المشروع

```
govagent/
├── frontend/          واجهة Next.js عربية RTL
│   ├── app/           صفحات App Router
│   ├── components/    مكونات الواجهة
│   ├── lib/           عميل الـAPI وبيانات تجريبية
│   └── public/
├── backend/           خدمة FastAPI
│   ├── app/
│   │   ├── api/       مسارات HTTP
│   │   ├── ai/        مزودات المودل والواجهة المشتركة
│   │   ├── core/      الإعدادات
│   │   ├── database/  طبقة Oracle (لم تُنفّذ بعد)
│   │   ├── schemas/   نماذج الطلب والرد
│   │   ├── services/  منطق العمل
│   │   └── main.py
│   └── tests/
├── database/schema.sql   مخطط Oracle
├── docs/                 قواعد الفريق وملف المهام
├── mock-data/            بيانات تجريبية
└── .env.example
```

## متطلبات التشغيل

- Node.js 20 أو أحدث
- Python 3.11 أو أحدث
- لا حاجة إلى Oracle ولا إلى بيانات اعتماد OCI لتشغيل الـStarter.

## الإعداد

انسخ ملف البيئة النموذجي:

```bash
cp .env.example .env
```

القيم الافتراضية كافية للتشغيل المحلي. اترك حقول Oracle و OCI فارغة.

## تشغيل الـBackend

```bash
cd backend && python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
```

ثم:

```bash
cd backend && .venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
```

- فحص الحالة: <http://localhost:8000/health>
- توثيق Swagger: <http://localhost:8000/docs>

على لينكس أو ماك استبدل `.venv/Scripts/` بـ`.venv/bin/`.

## تشغيل الـFrontend

```bash
cd frontend && npm install
```

ثم:

```bash
cd frontend && npm run dev
```

الواجهة على <http://localhost:3000>. شغّل الـBackend أولًا حتى تعمل المحادثة.

## مزود المودل

يُختار المزود من متغير واحد في `.env`:

| القيمة   | الوصف                                                   |
| -------- | ------------------------------------------------------- |
| `mock`   | الافتراضي. يعمل بلا Oracle ويعيد ردًا تجريبيًا واضحًا.   |
| `oracle` | OCI Generative AI — غير منفّذ بعد (مهمة AI-02).          |
| `local`  | مودل داخل سيرفر الجهة — واجهة مستقبلية فقط.             |

```env
MODEL_PROVIDER=mock
```

القيمة غير المدعومة تُنتج رسالة خطأ واضحة تذكر القيم المقبولة.

## تحذير أمني

لا ترفع ملف `.env` ولا أي مفتاح أو بيانات اعتماد إلى المستودع.
`.env.example` فقط هو المسموح رفعه، ويجب أن يبقى بلا قيم حقيقية.
